# Voxel Sniper 教程

Voxel Sniper（简称 VS）是一个强大的笔刷工具，主要适用于打造地形、雕刻和概念设计。它通过点击操作来精细地修改地形，是地形塑造的利器！

## 快速开始

VS 使用两种物品作为操作工具：

- **箭（Arrow）**：左键操作
- **火药（Gunpowder）**：右键操作

通过不同的指令，你可以切换笔刷类型、设置方块样式、调整笔刷大小等。

:::tip
第一次使用 VS 时，建议先用 `/d` 命令重置所有设置，确保从干净的状态开始！
:::
