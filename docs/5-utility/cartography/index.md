# 地图画生成器

目前已可在**菜单**内使用地图画生成
请使用`/bs`查看
支持更改：
- url
- 宽度(length)
- 高度(width)
- 保持比例(keepscale)
- 抖动算法(dither)
- 打包方式（潜影盒、普通、压缩画）

# 命令生成地图画

命令格式：`/getimage <URL选项> [地图画宽度选项] [地图画高度选项> [抖动算法选项] [保持比例选项] [打包选项]`
（你可以任意调整参数顺序）
## 具体格式说明：

- **`<URL选项>`：** `-url <图片URL>`（例如：https://i.imgs.ovh/2025/08/23/GxYxd.jpeg ）
- **`[地图画宽度选项]`：** `-l <正整数>` 默认为1
- **`[地图画高度选项]`：** `-w <正整数>` 默认为1
- **`[抖动算法选项]`：** `-dither` 输入则使用该算法，默认不使用
- **`[保持比例选项]`：** `-keepscale` 输入则使用该算法，默认不使用
- **`[打包选项]`：** `-pack` `<打包方式>`
- **`<打包方式>`：**
  1. `normal`（直接放入背包，默认）
  2. `compressed`（存储于压缩画中）
  3. `shulker`（存储于潜影盒中）

**样例：** `/getimage -url https://i.imgs.ovh/2025/08/23/GxYxd.jpeg -l 2 -w 2 -keepscale -pack compressed`

**解析：** 直接获取`URL为https://i.imgs.ovh/2025/08/23/GxYxd.jpeg` `宽为2格` `高为2格` `保持比例` `使用压缩画存储` `（不使用抖动算法）` 的地图画
