# Arceon 教程

Arceon 是一个强大的 WorldEdit 扩展插件，提供了许多高级建筑工具和笔刷，专门用于复杂建筑和地形塑造。

## 快速导航

### 基础功能

- [笔刷](./brushes) - 各种建筑笔刷
- [蒙版](./masks) - 蒙版使用技巧
- [图案](./patterns) - 图案和样式

### 工具列表

- [Resize 工具](./resize-tool) - 调整大小工具
- [Terragen 噪声](./terragen) - 地形生成噪声
- [河流工具](./river-tool) - 创建河流
- [雪地工具](./smooth-snow-tool) - 平滑雪面
- [Type Replace](./type-replace) - 方块类型替换
- [旋转工具](./revolve-tool) - 旋转复制
- [尖刺工具](./spike-tool) - 生成尖刺
- [修路工具](./road-tool) - **新增** - 道路生成
- [屋顶工具](./roof-tool) - 屋顶生成
- [Loft 工具](./loft-tool) - 放样工具
- [方块颜色替换工具](./color-replace) - 颜色替换
- [Smear 工具](./smear-tool) - 涂抹工具
- [文字工具](./text-tool) - 文字生成
- [阴影工具](./shadow-tool) - 阴影生成
- [拱门工具](./arch.md) - 拱门生成
- [实验性工具](./experimental-tools) - 实验性功能

:::tip
Arceon 的笔刷命令通常以 `/arcbrush` 或 `/ab` 开头，比普通 WorldEdit 笔刷更强大！
:::
