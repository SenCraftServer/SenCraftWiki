# 自定义群系颜色

## 命令

| 命令                                              | 描述             |
|-------------------------------------------------|----------------|
| `//getbiomecolors`                              | 获取你所在群系的颜色     |
| `//setgrasscolor #hexcode [biome:name]`         | 改变草、蕨类植物和甘蔗的颜色 |
| `//setfoliagecolor #hexcode [biome:name]`       | 改变树叶和藤蔓的颜色     |
| `//setdryfoliagecolor #hexcode [biome:name]`    | 改变枯叶的颜色        |
| `//setwatercolor #hexcode [biome:name]`         | 改变水的颜色         |
| `//setwaterfogcolor #hexcode [biome:name]`      | 改变在水中雾的颜色      |
| `//setskycolor #hexcode [biome:name]`           | 改变天空的颜色        |
| `//setfogcolor #hexcode [biome:name]`           | 改变雾的颜色         |
| `//setsunrisesunsetcolor #hexcode [biome:name]` | 改变天空日出日落的颜色    |
| `//setcloudcolor #hexcode [biome:name]`         | 改变云的颜色         |
| `//setskylightcolor #hexcode [biome:name]`      | 改变天空光的颜色       |

> `#hexcode` [为16进制颜色代码](https://c.runoob.com/front-end/6210/)

`biome:name`  (可选) 按 F3 时显示的群系名称
