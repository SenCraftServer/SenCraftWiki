# WorldEdit 教程

WorldEdit（简称 WE）是 Minecraft 中最强大的建筑工具之一，掌握后可以极大提升建筑效率。FAWE（Fast Async World Edit）是 WorldEdit 的高性能分支，运行速度大幅提升，并提供了更多高级功能。

## 快速开始

按 `/` 或 `t` 打开聊天框，输入以下指令：

```bash
//wand

:::tip
你可以用 `/toggleeditwand` 来切换魔杖功能，这样小木斧就可以正常用来砍树了！
:::
```

你会获得一把**小木斧**——这是 WorldEdit 的默认选区工具。

### 第一次操作

1. **左键点击**一个方块设置第一个选区点（pos1）
1. **右键点击**另一个方块设置第二个选区点（pos2）
1. 输入指令填充选区：

```bash
//set lava
```

选区内的所有方块会被替换成岩浆！

### 撤销操作

如果操作失误，可以使用撤销命令：

```bash
//undo
```

:::tip
可以连续撤销多次，每次撤销一步操作。使用 `//redo` 可以重做被撤销的操作。
:::

## 方块填充示例

除了岩浆，你还可以填充其他方块。使用 `//set <方块ID>` 命令：

| 命令示例 | 说明 |
|---------|------|
| `//set oak_slab` | 填充橡木台阶 |
| `//set stone` | 填充石头 |
| `//set ##leaves` | 随机填充各种树叶 |
| `//set white` | 填充白色方块（羊毛/混凝土等） |
| `//set #cell[2][pink,cyan]` | 创建棋盘格图案（粉色和青色） |

:::tip
使用快捷键 `F3 + H` 可以启用高级工具提示，在物品栏中把鼠标悬停在物品上就能看到该物品的技术 ID。
:::

:::info
推荐安装 **WECUI（WorldEdit CUI）** 模组，它可以在游戏中直观地显示选区范围，让建筑更加方便！
:::
