# 笔刷

**命令别名：** `/arcbrush`、`/ab`、`//ab`

## 笔刷列表

### 侵蚀笔刷 (Erode Blend)

**权限节点：** `worldedit.brush.erodeblend`

```
/arcbrush erodeblend <大小> [类型]
```

创建侵蚀球形笔刷，用于自然地改变地形。

**类型选项：** Fill（填充）、Smooth（平滑）、Lift（提升）、Melt（融化）、Clear（清除）

---

### 方块笔刷 (Cube)

**权限节点：** `worldedit.brush.cube`

```
/arcbrush cube <方块> [大小] [倾斜角度] [高度] [宽度]
```

创建立方体形状。你也可以使用 `[min][max]` 格式来设置尺寸。

**参数标志：**
- `-h`：生成空心立方体
- `-c`：高度居中
- `-a`：根据玩家位置计算倾斜

![](/arceon/images/cube.png)

:::tip
使用 `-c` 标志可以让立方体以你点击的位置为中心生成！
:::

---

### 尖刺笔刷 (Spike)

**权限节点：** `worldedit.brush.spike`

```
/arcbrush spike <方块> <长度> <头部半径> <尾部半径>
```

> 请使用凸面体选区（convex）

**参数标志：**
- `-n`：在尖刺上添加噪波，使其更自然

![](/arceon/images/spike.png)

---

### 藤蔓笔刷 (Vine)

**权限节点：** `worldedit.brush.vine`

```
/arcbrush vine <方块> [大小] [百分比] [生长率]
```

在墙壁或其他表面上生成藤蔓。

![](/arceon/images/vine.png)

---

### 农作物笔刷 (Crop)

**权限节点：** `worldedit.brush.crop`

```
/arcbrush crop <大小> <min> [max]
```

生成农作物。min 和 max 的数值只能在 0~8 之间。

![](/arceon/images/crop.png)

---

### 旋转笔刷 (Revolve)

**权限节点：** `worldedit.brush.revolve`

```
/brush revolve <旋转次数> [起点角度] [终点角度] [起点与终点的高度差]
```

> 请使用立方体选区（cuboid）

**使用方法：**
1. 选择想要旋转的东西
2. 输入指令
3. 点击旋转中心点

**参数标志：**
- `-p`：使用多边形旋转
- `-r`：方向旋转

![](/arceon/images/rev.png)

---

### 岩石笔刷 (Boulder)

**权限节点：** `worldedit.brush.boulder`

```
/arcbrush boulder <方块> [大小] [平滑度] [高度] [宽度]
```

生成自然的岩石形状。

**参数说明：**
- 平滑度范围：0 到 5（数值越小，棱角越分明）

**参数标志：**
- `-h`：生成空心岩石
- `-f`：使岩石生成在地面上
- `-a`：根据玩家方向倾斜

![](/arceon/images/bo.png)
