# 🧭 SenCraft 社区指南

学习 SenCraft 的各种建筑工具，包括 [**WorldEdit**](4-build-new/we) ，[**Arceon**](4-build-new/arceon) ，[**VoxelSniper**](4-build-new/vs) 等

  - 为每人提供4块512大 [**地皮**](2-plots/Start)
  - 无门槛生成 [**属于你的领域**](3-worlds/realms)
  - [快速调音](5-utility/blocktuner)功能（*红石音乐狂喜*)
  - 方便的[上传建筑](1-join/import-export)
  - 支持 [**Java**](https://zh.minecraft.wiki/w/Java%E7%89%88) 和 [**基岩**](https://zh.minecraft.wiki/w/%E5%9F%BA%E5%B2%A9%E7%89%88) 版，无论你用什么设备，都能一起游玩
  - 云端存档、定期备份，安全可靠

  ![](/cover.png)

## 服务器地址

```bash [Java 版]
mc.sencraft.top
```

```bash [基岩版]
mcbe.sencraft.top:35032
```

建议使用 Java 版，至少 1.19.4 或更高进入

## ⚒ 工欲善其事，必先利其器

### Fast Async World Edit

FAWE 是创世神的一个超集，大幅优化了性能，而且[**上手简单**](4-build-new/we/start)

### Arceon

包括模板，文字生成和河流等[**一些好用的工具**](4-build-new/arceon/Home)

### Voxel Sniper

使用箭和火药工具来编辑方块，雕刻利器，包含[**大量不同笔刷**](4-build-new/vs/Start)

### 不怕建筑被熊

你可以自行管理你的[**地皮**](2-plots/Start)或者[**领域**](3-worlds/realms)，谁能一起建筑、由你决定

### 还能[**申请优秀建筑**](1-join/eb)

SenCraft 分两个优秀建筑评级，**β** 为在服务器中脱颖而出的作品，其中最惊艳的将评为 **α**

### 导入和导出你的建筑

本地存档的建筑可以[自助上传](1-join/import-export#导入schem)，也可以[下载你的作品](1-join/import-export#导出schem)
