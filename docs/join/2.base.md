# 初来乍到

:::success ✨ 欢迎来到 SenCraft 森世界！
初来乍到可能感觉手足无措、不知道怎么开始玩？别慌！往下阅读，开启你的森世界之旅吧！
:::

## 第一步：准备好 Minecraft

在开始之前，先确保你已经安装好 Minecraft 啦～

- 如果你是 [Java 版](https://zh.minecraft.wiki/w/Java%E7%89%88) 玩家，确保版本至少为 [1.7.2](https://zh.minecraft.wiki/w/Java%E7%89%881.7.2)（当然越新越好！）
- 基岩版体验较差，不推荐作为主要游玩方式，如果一定要用，请确保是最新的稳定版

:::tip 🎮 还没下载 Minecraft？
不会下载 Minecraft ？[点这里解决](./problem/mc)
:::

## 第二步：服务器地址

准备好游戏后，就可以连接服务器啦！根据你的网络情况选择合适的地址：

### Java 版

```bash
## 主线（推荐首选）
mc.sencraft.top

## 国内备线（临时）
bpcn.sencraft.top
dx.mc.sencraft.top  # 电信专属
ly.mc.sencraft.top  # 联通专属
yd.mc.sencraft.top  # 移动专属

## 海外备线（临时）
bpus.sencraft.top
```

### 基岩版

```bash
mcbe.sencraft.top:35033
```

:::tip 🌐 选哪个地址好？
- 国内玩家优先尝试主线 `mc.sencraft.top`
- 如果连接不稳定，再尝试对应运营商的备线
- 海外玩家试试海外备线 `bpus.sencraft.top`
:::

## 第三步：进入服务器

恭喜你成功进入服务器啦🎉！

刚开始可能会有点不知所措，没关系，按这个步骤来：

1. **先领取一块地皮** —— 输入指令 `/p auto` 自动领取一块属于你的地皮
2. **开始你的创作** —— 地皮就是你的专属画布，想建什么就建什么！

:::tip 🏠 关于地皮
想了解更多关于地皮系统的信息？[点这里查看详细说明](./plots/1.Start)
:::

祝你在 SenCraft 玩得开心！🎮✨
