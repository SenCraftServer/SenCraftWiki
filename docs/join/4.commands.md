# 基础指令 💻

想要在 SenCraft 玩得溜，这些基础指令你必须掌握！把它们收藏好，关键时刻能救命（误）

:::tip 📌 命令小贴士
- 命令中的 `[ ]` 表示可选参数，`< >` 表示必填参数
- 很多命令都有简写，比如 `/login` 可以写成 `/l`
- 按 `Tab` 键可以自动补全命令和玩家名，超好用！
:::

## 账号相关 🔐

先把账号安全搞定，这是玩游戏的第一步！

| 指令 | 描述 | 示例 |
| --- | --- | --- |
| `/reg <密码> <确认密码>` | 新玩家注册（第一次进服必用） | `/reg 114514 114514` |
| `/login <密码>` 或 `/l <密码>` | 登录服务器 | `/l 114514` |
| `/logout` | 安全登出 | 无需参数 |
| `/changepassword <旧密码> <新密码>` | 修改密码，定期改密码更安全哦 | `/changepassword 114514 s1hs5d1c3=` |

:::caution 🔒 密码安全提醒
- 不要用太简单的密码，比如 `123456` 这种分分钟被破解
- 也别用文档里的示例密码！示例只是示例！
- 建议密码包含大小写字母、数字和特殊字符
:::

## 实用小工具 🛠️

这些命令能让你的游戏体验提升不止一个档次！

| 指令 | 描述 | 补充说明 |
| --- | --- | --- |
| `/ender` 或 `/oe` | 打开 [**末影箱**](https://zh.minecraft.wiki/w/%E6%9C%AB%E5%BD%B1%E7%AE%B1) | 随身储物箱，走到哪用到哪 |
| `/afk` | 标记自己为暂时离开状态 | 挂机钓鱼必备，别人就知道你不在啦 |
| `/balance` | 查询你的森币余额 | 有钱才能买买买！ |
| `/head` | 获得自己的头颅 | 装饰你的小窝 |
| `/fly` | 开启/关闭飞行模式 | 建筑党狂喜，再也不用搭脚手架了 |
| `/hat` | 把手上的物品戴到头上 | 想戴什么戴什么，就是这么任性 |
| `/near <范围>` | 查看附近的玩家 | 看看谁在附近摸鱼 |
| `/sit` | 坐下休息 | 找个地方歇歇脚 |
| `/gm <模式>` | 设置游戏模式 | `/gm 1` 创造，`/gm 0` 生存 |
| `/idm <on/off>` | 开关死亡信息提示 | 不想看刷屏可以关掉 |
| `/nv` | 开关夜视效果 | 妈妈再也不用担心我看不见了 |
| `/ptime <时间>` | 设置自己的个人时间 | 想白天就白天，想黑夜就黑夜 |
| `/skin set <玩家名>` | 更换皮肤 | 用别人的皮肤也可以哦 |
| `/crawl` | 爬行（阴暗地爬行🕷️） | 整活必备 |
| `/lay` | 躺下 | 可以和爬行结合玩出花 🤸 |

:::tip ✨ 快捷操作
- `/fly` 和 `/nv` 这些开关类命令，输入一次开启，再输入一次就关闭
- 想快速切换游戏模式？记住 `/gm 1` 是创造，`/gm 0` 是生存
:::

## 传送系统 🚀

在 SenCraft，想去哪里就去哪里，就是这么自由！

| 指令 | 描述 | 示例 |
| --- | --- | --- |
| `/tp <玩家名>` | 直接传送到玩家身边 | `/tp ifctmzzz` |
| `/tpa <玩家名>` | 请求传送到玩家那里（需要对方同意） | `/tpa ZWT826` |
| `/tpahere <玩家名>` | 请求玩家传送到你这里 | `/tpahere ZWT826` |
| `/back` | 返回上一个传送点 | 无需参数 |
| `/warp <地标名>` 或 `/warps <地标名>` | 传送到服务器地标 | `/warps build_ysxq` |
| `/sethome <家的名字>` | 设置一个家 | `/sethome MyHouse` |
| `/home <家的名字>` 或 `/homes <家的名字>` | 传送回家 | `/home MyHouse` |
| `/delhome <家的名字>` | 删除一个家 | `/delhome MyHouse` |

:::tip 🏠 家的设置小技巧
- 你可以设置多个家！比如给你的作品单独设一个家
- `/home` 不加名字会传送到默认的家
- 地标太多记不住？输入 `/warps` 可以查看所有地标列表
:::

:::caution ⚠️ 传送注意事项
- `/tp` 是强制传送，不要随便乱用哦
- `/tpa` 比较礼貌，建议优先使用请求传送
- 误传了？赶紧用 `/back` 回去！
:::

## 查看服务器状态 📊

想知道服务器运行得怎么样？用这些命令查一查：

| 指令 | 描述 |
| --- | --- |
| `/tps` | 查看服务器 TPS（刻每秒），20 是满分 |
| `/mem` | 查看服务器内存使用情况 |
| `/tickinfo` | 查看更详细的服务器刻信息 |

:::info 📈 什么是 TPS？
TPS 是 Ticks Per Second 的缩写，也就是每秒刻数。Minecraft 正常运行是 20 TPS，如果低于这个数，服务器就会卡顿。一般来说 18 以上都还算流畅，15 以下就需要注意啦！
:::

## 聊天交流 💬

和小伙伴们愉快地聊天，这些命令必不可少：

| 指令 | 描述 | 示例 |
| --- | --- | --- |
| `/msg <玩家> <内容>` 或 `/w <玩家> <内容>` | 发送私聊消息 | `/w HoShiNoMino 嗨` |
| `/reply <内容>` 或 `r <内容>` | 回复最新的私聊 | `/r 好久不见啊` |
| `/ignore <玩家名>` | 屏蔽指定玩家的消息 | `/ignore ikundows` |
| `/mail read` | 阅读邮件 | 无需参数 |
| `/mail clear` | 清空邮箱 | 无需参数 |
| `/mail send <玩家> <内容>` | 给玩家发送邮件 | `/mail send Ker__ 能教我雕塑吗？` |

:::tip 💌 邮件小妙用
- 玩家不在线时，可以用邮件给他留言
- 重要的事情也可以用邮件记录下来，防止忘记
- 邮箱满了记得清空哦！
:::
