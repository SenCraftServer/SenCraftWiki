# 收到了奇奇怪怪的提示

![npb-oversize](https://github.com/Lumine1909/NoPacketBan/raw/master/oversize.png)
如果你看到包含`PacketTooLarge`的提示，意味着你收到了过大的数据包，这可能是由于禁人书/盒子/方块/区块导致的。你可能需要清理背包，离开当前区块，并向管理员报告。


![npb-viabug](https://github.com/Lumine1909/NoPacketBan/raw/master/viabug.png)
如果你看到包含`viaversion`的提示，意味着ViaVersion插件的转写出了问题，这可能是由于禁人物品或ViaVersion插件本身的bug导致的。你可能需要清理背包，并向管理员报告。
