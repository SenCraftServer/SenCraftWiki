# 代码块与终端样式优化规范

## Why
当前网站的代码块和终端组件存在可读性问题：代码文本颜色对比度不足，在浅色背景下显示为深色难以辨认；终端组件悬停时有颜色变化动画，造成视觉干扰。需要针对这些具体问题进行优化。

## What Changes
- 优化 `code` 内联代码文本的配色方案，提升文本可读性
- 优化 `pre` 代码块的样式，确保语法高亮清晰可见
- 移除终端组件的悬停颜色变化动效，保持终端原有颜色状态

## Impact
- Affected specs: 代码显示样式、终端组件样式
- Affected code:
  - `src/css/custom.css` - 代码块和终端样式
  - `src/pages/index.module.css` - 终端组件样式

## ADDED Requirements
无新增需求，仅为现有样式的优化调整。

## MODIFIED Requirements

### Requirement: 代码块文本可读性优化
优化代码块的文本颜色和背景色，确保高对比度和清晰可读。

**变更内容**：
- 浅色模式下代码块使用深色文字（#1a1a1a 或更黑）确保对比度
- 深色模式下代码块使用浅色文字（#e6e6e6 或更亮）确保对比度
- 背景色与文字颜色形成鲜明对比
- 保持 Prism 语法高亮功能不受影响
- 适当调整字体大小、行高和字间距

### Requirement: 终端悬停效果移除
移除终端组件的悬停颜色变化动效。

**变更内容**：
- 移除 `.terminalWindow:hover::before` 的 opacity 变化效果
- 移除悬停时的边框发光增强效果
- 保持终端原始颜色状态不变
- 确保用户在操作过程中不会因颜色变化产生视觉干扰

## REMOVED Requirements
无移除的需求。

## 验证标准
- 代码块文本在浅色和深色模式下都清晰可读
- 代码文本与背景的对比度符合 WCAG AA 标准（至少 4.5:1）
- 终端悬停时颜色保持稳定，无动画变化
- 语法高亮功能正常工作
